Each of these is a caricature — a mechanism drawn small enough to watch, not a measurement of anything.

Rivalry is symmetrical schismogenesis: each answers boasting with boasting, so the pair climbs together. Dominance is complementary: assertion draws out submission, which invites more assertion, so the pair forks. Bateson argued in Naven (1936) that either runs to breakdown unless something checks it — restraint, or the two patterns held against each other.

Read as politics, the two pens are each party's distance from the centre, so the distance between the parties is their sum. That makes left–right polarisation a symmetrical process: the two sides are not doing opposite things, they are doing the same thing in opposite directions. What the model then insists on is that no amount of anger makes the process run away on its own — only the loss of whatever used to pull both sides back. That is a claim about this model, not a finding about any country.
